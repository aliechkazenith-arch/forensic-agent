### Deliverables Created in Phase 1
1. **`pyproject.toml`**: Configured project package metadata for `forensicops-ai` with dependencies (`fastapi`, `uvicorn`, `pydantic>=2.0`, `duckdb`, `httpx`, `pyyaml`, `langgraph`, `pytest`, `pytest-asyncio`) and pytest asyncio settings.
2. **`backend/app/models/custody.py`**:
   - `ArtifactRecord`: Pydantic v2 frozen model for immutable evidence records (`artifact_id`, `case_id`, `type`, `original_path`, `blob_path`, `size_bytes`, `sha256`, `sha512`, `acquired_utc`, `acquisition_method`).
   - `CustodyChainEntry`: Cryptographically chained ledger model (`seq_id`, `case_id`, `timestamp_utc`, `actor`, `action`, `artifact_sha256`, `tool_id`, `prev_hash`, `entry_hash`) enforcing canonical RFC 8785 JSON hashing (`entry_hash = sha256(prev_hash + canonical_json)`).
   - `CapsuleManifest` & `ManifestArtifactEntry`: Parser schemas for collector capsules generated by endpoint collectors.
3. **`backend/app/core/exceptions.py`**: Dedicated security exceptions (`ZipSlipError`, `SuspiciousArchiveError`, `DecompressionBombError`, `HashMismatchError`, `CustodyTamperError`, `VaultIntegrityError`).
4. **`backend/app/core/custody_engine.py`**:
   - **Streaming Zip Guard**: Proactive memory and stream inspection blocking Zip Slip (`..`, absolute paths), symlinks/hardlinks, and decompression bombs (ratio > 100x and byte quotas).
   - **Defanged `.blob` Vault**: Strips all executable extensions (`.exe`, `.ps1`, `.bat`, `.dll`, etc.), enforces `0400` / `S_IREAD` read-only permissions, and saves files content-addressed at `vault/blobs/<sha256[:2]>/<sha256>.blob`.
   - **Zero-Copy Read-Only Path Reference (`:ro`)**: Streams large disk/VM images (`.E01`, `.vmdk`, `.raw`, `.vhdx`) in userspace to compute SHA-256 and SHA-512 without host kernel mounting or disk space duplication.
   - **Collector Capsule Unpacker**: Safe extraction with dual-hash verification (SHA-256 and SHA-512) against `manifest.json`.
   - **Append-Only SQLite Custody Ledger**: Atomic WAL-mode table insertion with cryptographic hash chaining and `verify_chain_integrity()` tamper detection.
   - **Audit Transparency Log (`audit.jsonl`)**: Immediate disk-synced audit trail for zero silent sampling.
5. **`backend/tests/test_phase1_custody.py`**: 12 comprehensive unit and security edge-case tests validating all components.
